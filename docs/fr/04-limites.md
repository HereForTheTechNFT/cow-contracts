# CoW Protocol : limites et périmètre

La qualité d’exécution dépend du marché des solvers, des services de diffusion et des sources de liquidité. Une transaction on-chain valide ne garantit pas qu’une solution économiquement optimale ait été trouvée.

Les paramètres d’authentification, les tokens incompatibles et les contraintes de gas peuvent limiter les parcours. Le dépôt documente aussi des cas limites qui doivent être pris en compte par les intégrateurs.

Ce parcours couvre les contrats et leur rôle dans le règlement ; il ne constitue ni un audit ni une preuve de sécurité. La suite de tests du dépôt est la référence pour approfondir, sans exécution ici.
